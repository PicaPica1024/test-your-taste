# Test Your Taste

公开游戏地址：<https://test-your-taste.zhujiangqiu.chatgpt.site/>

网站工具是论文、答案和计分的唯一来源。不要编造、补全、翻译或用搜索结果替换游戏数据。答题前不得搜索论文标题、摘要、作者、期刊或引用量。

## 帮助命令

如果命令内容去除空格后等于 `help`、`--help` 或 `帮助`，只输出下面内容，不访问网站：

```text
Test Your Taste 使用方法

和你一起玩：
@testyourtaste "关键词A, 关键词B"

让 AI 自己闭卷玩：
@testyourtaste ai "关键词A, 关键词B"

先看论文的年份、标题和摘要，再猜：
1. 发表档次（五选一）
2. 引用量区间（五选一）

作答前会先问你是否读过这篇论文；读过或不确定就换一篇，不计分。

Codex 中也可以写：
$testyourtaste "关键词A, 关键词B"
```

## 解析命令

1. 读取调用名后面的内容，去掉一对匹配的中英文引号。
2. 如果内容以独立的 `ai` 开头，进入 AI 自测模式，并移除这个前缀；否则是用户作答模式。
3. 按中英文逗号或分号拆分关键词，去掉空项并按原顺序去重，再用空格连接。
4. 查询必须为 2–120 个字符。没有关键词时，请用户补充后停止。
5. 如果用户输入的是网站预设学科的完整英文名称（例如 `Ecology` 或 `Biodiversity Conservation`），仍传给 `keyword`；网站会自动切换到该预设学科并纳入匿名基准。其他输入作为自定义关键词练习。

## 获取论文并确认熟悉度

1. 打开或复用公开游戏首页，并调用 `start_research_taste_game`，将整理后的关键词传给 `keyword`。
2. 工具只会返回年代、标题和摘要，不会返回答案。原样输出这些内容。
3. 用户作答模式下，先问：`你以前读过或认出这篇论文吗？请回复：没读过 / 读过 / 不确定。`
4. 将回答映射为 `new`、`read` 或 `unsure`，调用 `confirm_paper_familiarity`：
   - `new`：继续显示题目；
   - `read` 或 `unsure`：网站会换一篇同档次论文且不计分。输出新论文，再次询问熟悉度。
5. AI 自测模式下，不询问用户，直接以 `new` 调用熟悉度工具。AI 必须只依据工具返回的年份、标题和摘要判断，不使用网页搜索、文献工具或其他外部资料。说明：无法保证模型训练时从未见过该论文，因此 AI 成绩只供参考。

## 显示题目

熟悉度确认完成后，严格按下面结构显示：

```text
问题 1：这项研究发表在什么档次的期刊或会议？
A. 综合顶刊 / 旗舰子刊
B. 领域顶刊
C. 普通 JCR 一区
D. JCR 二区
E. 其他

问题 2：这篇论文被引用了多少次？
A. 0–25
B. 26–100
C. 101–300
D. 301–1000
E. >1000

请回复两个字母，例如：B, D。
```

五轮为一组，五个发表档次各出现一次，顺序随机。不要暗示当前论文来自哪个档次。

## 提交答案

发表档次映射：

- A → `flagship`
- B → `field-top`
- C → `q1`
- D → `q2`
- E → `other`

引用量映射：

- A → `0-25`
- B → `26-100`
- C → `101-300`
- D → `301-1000`
- E → `1001+`

用户作答模式调用 `submit_taste_guess` 时传 `playerType: human`；AI 自测模式传 `playerType: ai`。同时传入 `venueTier` 和 `citationRange`。以网站返回结果为准，报告：实际期刊或会议、实际档次、准确引用量、两题正误和本轮得分。

公布结果后询问继续相同关键词、换关键词还是停止。

## 异常处理

- 网站工具不可用时，提供公开游戏链接，并说明当前环境无法在聊天内提交答案。不要假装成功。
- 某档没有找到合适论文时，用同一查询重试一次；仍失败则建议减少关键词或改用预设学科。
- 只使用中文或英文论文；引用量来自 OpenAlex，会随时间变化。
